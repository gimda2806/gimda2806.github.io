개인정보처리방침 (Privacy Policy)

시행일 / Effective date: 2026-11-22

1. 이 앱은 무엇인가요

shorts-uploader는 채널 운영자 한 사람이 본인의 YouTube 채널에 본인이 만든 영상을 올리기 위해 쓰는 개인용 도구입니다. 일반 사용자에게 제공되는 서비스가 아닙니다.

2. 사용하는 Google 데이터

  • YouTube 업로드 권한(youtube.upload)과 채널 정보 읽기 권한: 운영자 본인 채널에 영상을 비공개로 올리고, 올린 영상의 공개 상태를 확인하는 데만 씁니다.
  • 로그인 토큰(OAuth 토큰): 운영자 본인 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다.

3. 공유·판매하지 않습니다

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고·AI 모델 학습에 쓰지 않습니다. shorts-uploader의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관과 삭제

토큰은 운영자가 도구를 쓰는 동안만 보관하며, 언제든 Google 계정 권한 페이지에서 접근 권한을 취소할 수 있습니다. 취소하거나 토큰 파일을 지우면 즉시 사용이 중단됩니다.

5. 문의

Google 동의 화면에 표시된 지원 이메일로 연락해 주세요.

English

What it is. shorts-uploader is a personal tool used by a single channel owner to upload their own videos to their own YouTube channels. It is not offered to the general public.

Data used. The YouTube upload scope and read-only channel access are used only to upload videos as private to the owner's channels and to check their privacy status. OAuth tokens are stored only on the owner's own computer and are never sent to any other server.

No sharing. Google user data is never sold or shared with third parties, and is not used for advertising or for training AI models. shorts-uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion. Tokens are kept only while the tool is in use. Access can be revoked at any time at Google Account permissions.

Contact. Please use the support email shown on the Google consent screen.
